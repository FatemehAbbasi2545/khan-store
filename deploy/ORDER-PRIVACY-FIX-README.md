# اصلاح حریم خصوصی سفارش — بسته تجمیعی

**نسخه جدیدتر:** الزام ورود برای پرداخت و آیکون جدید سبد در بسته‌های login-checkout اضافه شده‌اند. برای انتشار جدید از LOGIN-CHECKOUT-README.md استفاده کنید؛ توضیح خرید مهمان در این راهنما مربوط به نسخه قبلی است. فایل‌های latest اکنون همان بسته‌های login-checkout هستند.

فایل‌های `khan-store-backend-order-privacy-fix.zip` و `khan-store-frontend-order-privacy-fix.zip` کل کد همان بخش، تغییرات قبلی سایت و اصلاحات امنیتی پرداخت را نیز دارند.

## بارگذاری در لیارا

۱. در تنظیمات بک‌اند، `ADMIN_JWT_SECRET` را بررسی کنید: مقدار اختصاصی و تصادفی حداقل ۳۲ کاراکتری لازم است. مقدار خالی، `khan-dev-secret-change-me` و `change-me-too-a-long-random-string` دیگر پذیرفته نمی‌شوند. اگر مقدار فعلی قوی و اختصاصی است، آن را حفظ کنید. تغییر آن تمام توکن‌ها و نشست‌های قبلی را نامعتبر می‌کند.

۲. برای تولید کلید جدید روی سیستم خودتان اجرا کنید:

```sh
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

خروجی را در تنظیمات امن بک‌اند لیارا وارد کنید؛ در سورس، چت یا فایل ZIP ذخیره نکنید.

۳. ابتدا ZIP بک‌اند و سپس ZIP فرانت‌اند را روی اپ‌های فعلی بارگذاری کنید. هر دو بخش لازم‌اند؛ فرانت‌اند قدیمی نمی‌تواند مجوز رسید مهمان را ذخیره کند. در فاصله استقرار دو اپ ممکن است checkout قدیمی مجوز قابل استفاده در مرورگر جدید نسازد؛ انتشارها را پشت سر هم و در زمان کم‌ترافیک انجام دهید.

۴. تنظیمات واقعی اتصال API، دیتابیس، دامنه‌ها و درگاه را حفظ کنید. `NEXT_PUBLIC_API_URL` فرانت‌اند باید از سرور فرانت‌اند هم قابل دسترس باشد. هیچ تغییر schema یا migration جدیدی در این بسته وجود ندارد. پیکربندی پرداخت تولید همچنان باید `NODE_ENV=production`، `ZARINPAL_SANDBOX=false`، شناسه واقعی پذیرنده و callback واقعی HTTPS داشته باشد.

## رفتار جدید

- شماره سفارش به‌تنهایی اطلاعاتی برنمی‌گرداند؛ کاربر ناشناس 401 دریافت می‌کند.
- مشتری دیگر و سفارش ناموجود پاسخ یکسان 404 دارند.
- مالک و مدیر می‌توانند خلاصه رسید را بگیرند. جزئیات شخصی از مسیرهای محافظت‌شده حساب/ادمین قابل دسترس است.
- مهمان فقط به رسید سفارش تازه خود دسترسی دارد. مجوز هفت‌روزه، مخصوص همان سفارش، در کوکی HttpOnly است؛ در URL یا JSON فرانت‌اند قرار نمی‌گیرد.
- رسید مهمان قدیمی، مرورگر دیگر یا دسترسی منقضی‌شده فقط با شماره سفارش باز نمی‌شود. صفحه برای این حالت راهنمای پیگیری نشان می‌دهد و ادعای شکست پرداخت نمی‌کند.
- پاسخ رسید فقط شامل شماره سفارش، وضعیت، مبلغ و مرجع پرداخت است؛ نام، شماره تماس، نشانی، Authority و اقلام در آن نیستند.

آزمون‌های خودکار با داده ساختگی و سرور HTTP محلی اجرا شده‌اند؛ دیتابیس و درگاه واقعی لیارا از این محیط آزمایش نشده‌اند. پس از انتشار، یک خرید کم‌مبلغ واقعی، برگشت از بانک، «سفارش‌های من» و رد دسترسی از مرورگر دیگر را بررسی کنید.

سایر یافته‌های باز گزارش، از جمله مالکیت آیتم سبد، در این مرحله اصلاح نشده‌اند.

# ورود اجباری برای نهایی کردن سفارش

از بسته‌های `khan-store-backend-login-checkout.zip` و `khan-store-frontend-login-checkout.zip` استفاده کنید. هرکدام کل کد همان بخش و تمام تغییرات قبلی سایت، امنیت پرداخت و حریم خصوصی سفارش را دارند. فایل‌های latest هم کپی همین نسخه هستند.

۱. مهمان می‌تواند کالا انتخاب کند، سبد را ببیند و اقلام و جمع مبلغ را بررسی کند.
۲. با انتخاب «نهایی کردن سفارش و پرداخت»، مهمان به ورود هدایت می‌شود. لینک ثبت‌نام هم مقصد تسویه‌حساب را حفظ می‌کند.
۳. پس از ورود، یا ثبت‌نام موفق همراه ورود خودکار، همان سبد حفظ می‌شود و فرم اطلاعات تحویل باز می‌شود.
۴. پس از تعیین محل و زمان تحویل، ثبت سفارش و انتقال به درگاه انجام می‌شود. سفارش به حساب مشتری واردشده متصل است.
۵. سرور هم مستقلاً ثبت سفارش مهمان و توکن منقضی یا نامعتبر را رد می‌کند. محدودیت صرفاً ظاهری نیست.
۶. آیکون سبد در هدر با طرح خطی سبد و برگ، رنگ زرشکی و برنزی، هماهنگ با آیکون حساب جایگزین شده است.

هر دو اپ باید به‌روزرسانی شوند: ابتدا بک‌اند و بلافاصله فرانت‌اند. تنظیمات امن JWT، درگاه واقعی، API و دیتابیس را حفظ کنید. تغییر schema یا migration جدید لازم نیست. راهنماهای قدیمی که خرید بدون ورود را توضیح می‌دهند، مربوط به نسخه‌های قبلی هستند.

آزمون امنیتی هر بخش: `npm run test:security`. تست‌ها از سرور HTTP محلی و داده ساختگی استفاده می‌کنند؛ پرداخت واقعی و مرورگر روی لیارا در این محیط آزمایش نشده‌اند.

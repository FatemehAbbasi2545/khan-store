# اصلاح کنترل مالکیت آیتم سبد

برای این تغییر، فایل `khan-store-backend-cart-ownership-fix.zip` را روی اپ بک‌اند فعلی لیارا بارگذاری کنید. فایل `khan-store-backend-latest.zip` کپی همین نسخه است. این بسته تمام تغییرات قبلی بک‌اند، شامل امنیت پرداخت، حریم خصوصی سفارش و ورود اجباری برای ثبت سفارش را هم دارد.

فرانت‌اند در این مرحله تغییر نکرده است. اگر نسخه login-checkout را قبلاً منتشر کرده‌اید، به بارگذاری دوباره فرانت‌اند نیاز نیست. اگر هنوز آن نسخه را منتشر نکرده‌اید، `khan-store-frontend-login-checkout.zip` یا `khan-store-frontend-latest.zip` را نیز منتشر کنید.

تغییر schema، migration یا متغیر محیطی جدید لازم نیست؛ تنظیمات موجود را حفظ کنید.

تغییر و حذف تنها وقتی انجام می‌شود که آیتم متعلق به همان سبدی باشد که توکنش در درخواست آمده است. آیتم سبد دیگر و آیتم ناموجود پاسخ یکسان 404 دارند. انتخاب کالا و مشاهده سبد برای مهمان همچنان آزاد است؛ ثبت سفارش نیاز به ورود دارد.

بررسی: `npm run test:security` در پوشه backend؛ بیلد و ۳۷ آزمون موفق بودند. هشت آزمون جدید از سرویس واقعی برنامه با دیتابیس ساختگی و HTTP محلی استفاده می‌کنند. دیتابیس و سرور زنده لیارا آزمایش یا به‌روزرسانی نشده‌اند.
